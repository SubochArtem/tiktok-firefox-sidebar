# tr

## Name

Kenar Çubuğunda TikTok

## Summary

Gezinirken TikTok'u Firefox kenar çubuğunda izleyin. İsteğe bağlı olarak sonraki videoya otomatik kaydırma. Resmi değildir, TikTok ile bağlantısı yoktur.

## Description

```text
Ana pencerede çalışmaya devam ederken TikTok akışını Firefox kenar çubuğunda izleyin.

Özellikler:
- Kenar çubuğunda TikTok: araç çubuğundaki düğmeyle veya Görünüm → Kenar çubuğu → TikTok menüsünden açıp kapatın.
- Otomatik kaydırma: mevcut video bittiğinde sonrakine geçmek için üstteki kutuyu işaretleyin.
- "TikTok uygulamasında devam et" uyarılarını gizler ve uygulama mağazalarına yönlendirmeleri engeller.
- Tarayıcıyı yeniden başlattığınızda oturumunuz açık kalır.

Gizlilik: eklenti hiçbir veri toplamaz ve TikTok'un kendisi dışında hiçbir yere bir şey göndermez.

Kaynak kodu: https://github.com/SubochArtem/tiktok-firefox-sidebar

Resmi olmayan bir projedir. TikTok ile bağlantılı değildir ve TikTok tarafından onaylanmamıştır.
```
