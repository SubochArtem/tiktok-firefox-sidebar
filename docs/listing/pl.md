# pl

## Name

TikTok w panelu bocznym

## Summary

Oglądaj TikToka w panelu bocznym Firefoksa podczas przeglądania. Opcjonalne automatyczne przewijanie do następnego filmu. Nieoficjalne, niezwiązane z TikTokiem.

## Description

```text
Oglądaj kanał TikToka w panelu bocznym Firefoksa, a w głównym oknie pracuj dalej.

Funkcje:
- TikTok w panelu bocznym: otwieraj i zamykaj go przyciskiem na pasku narzędzi lub przez Widok → Panel boczny → TikTok.
- Autoprzewijanie: zaznacz pole u góry, aby po zakończeniu filmu automatycznie przejść do następnego.
- Ukrywa komunikaty „kontynuuj w aplikacji TikTok” i blokuje przekierowania do sklepów z aplikacjami.
- Pozostajesz zalogowany po ponownym uruchomieniu przeglądarki.

Prywatność: rozszerzenie nie zbiera żadnych danych i niczego nigdzie nie wysyła, poza samym TikTokiem.

Kod źródłowy: https://github.com/SubochArtem/tiktok-firefox-sidebar

Projekt nieoficjalny. Niezwiązany z TikTokiem i niepopierany przez TikToka.
```
