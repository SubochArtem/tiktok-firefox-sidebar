# fr

## Name

TikTok dans la barre latérale

## Summary

Regardez TikTok dans la barre latérale de Firefox pendant que vous naviguez. Défilement automatique optionnel. Non officiel, sans lien avec TikTok.

## Description

```text
Regardez le fil TikTok dans la barre latérale de Firefox tout en continuant à travailler dans la fenêtre principale.

Fonctionnalités :
- TikTok dans la barre latérale : affichez-la ou masquez-la avec le bouton de la barre d’outils ou via Affichage → Panneau latéral → TikTok.
- Défilement automatique : cochez la case en haut pour passer à la vidéo suivante quand la vidéo en cours se termine.
- Masque les invitations « continuer dans l’application TikTok » et bloque les redirections vers les magasins d’applications.
- Vous restez connecté après un redémarrage du navigateur.

Confidentialité : l’extension ne collecte aucune donnée et n’envoie rien nulle part, sauf à TikTok lui-même.

Code source : https://github.com/SubochArtem/tiktok-firefox-sidebar

Projet non officiel. Sans lien avec TikTok et non approuvé par TikTok.
```
