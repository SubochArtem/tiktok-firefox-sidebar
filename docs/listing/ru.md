# ru

## Name

TikTok в боковой панели

## Summary

Смотрите TikTok в боковой панели Firefox, пока пользуетесь браузером. Автопрокрутка к следующему видео по желанию. Неофициальное, не связано с TikTok.

## Description

```text
Смотрите ленту TikTok в боковой панели Firefox и продолжайте работать в основном окне.

Возможности:
- TikTok в боковой панели: открывайте и закрывайте её кнопкой на панели инструментов или через Вид → Боковая панель → TikTok.
- Автопрокрутка: отметьте галочку вверху, чтобы после окончания видео автоматически включалось следующее.
- Скрывает предложения «продолжить в приложении TikTok» и блокирует переадресацию в магазины приложений.
- Вы остаётесь в аккаунте после перезапуска браузера.

Конфиденциальность: расширение не собирает данные и ничего никуда не отправляет, кроме самого TikTok.

Исходный код: https://github.com/SubochArtem/tiktok-firefox-sidebar

Неофициальный проект. Не связан с TikTok и не одобрен TikTok.
```
