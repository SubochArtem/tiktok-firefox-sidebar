# ja

## Name

TikTok をサイドバーで

## Summary

ブラウジングしながら Firefox のサイドバーで TikTok を視聴。次の動画への自動スクロールにも対応。非公式であり、TikTok とは関係ありません。

## Description

```text
メインウィンドウで作業を続けながら、Firefox のサイドバーで TikTok のフィードを視聴できます。

機能:
- サイドバーで TikTok: ツールバーのボタン、または 表示 → サイドバー → TikTok で表示/非表示を切り替えます。
- 自動スクロール: 上部のチェックボックスをオンにすると、動画が終わったときに次の動画へ自動で移動します。
- 「TikTok アプリで続ける」の案内を非表示にし、アプリストアへのリダイレクトをブロックします。
- ブラウザーを再起動してもログイン状態を保持します。

プライバシー: この拡張機能はデータを収集せず、TikTok 以外にはどこにも何も送信しません。

ソースコード: https://github.com/SubochArtem/tiktok-firefox-sidebar

非公式プロジェクトです。TikTok とは提携しておらず、TikTok による承認も受けていません。
```
