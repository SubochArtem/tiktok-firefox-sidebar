# es

## Name

TikTok en la barra lateral

## Summary

Mira TikTok en la barra lateral de Firefox mientras navegas. Desplazamiento automático opcional al siguiente vídeo. No oficial, sin relación con TikTok.

## Description

```text
Mira el feed de TikTok en la barra lateral de Firefox mientras sigues trabajando en la ventana principal.

Funciones:
- TikTok en la barra lateral: ábrela o ciérrala con el botón de la barra de herramientas o desde Ver → Barra lateral → TikTok.
- Desplazamiento automático: marca la casilla de arriba para pasar al siguiente vídeo cuando termine el actual.
- Oculta los avisos de "continuar en la app de TikTok" y bloquea las redirecciones a las tiendas de apps.
- Mantiene tu sesión iniciada entre reinicios del navegador.

Privacidad: la extensión no recopila datos y no envía nada a ningún sitio, salvo al propio TikTok.

Código fuente: https://github.com/SubochArtem/tiktok-firefox-sidebar

Proyecto no oficial. Sin relación con TikTok ni respaldado por TikTok.
```
