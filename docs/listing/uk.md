# uk

## Name

TikTok у бічній панелі

## Summary

Дивіться TikTok у бічній панелі Firefox, поки користуєтеся браузером. Автопрокручування до наступного відео за бажанням. Неофіційне, не пов’язане з TikTok.

## Description

```text
Дивіться стрічку TikTok у бічній панелі Firefox і продовжуйте працювати в основному вікні.

Можливості:
- TikTok у бічній панелі: відкривайте й закривайте її кнопкою на панелі інструментів або через Вигляд → Бічна панель → TikTok.
- Автопрокручування: позначте прапорець угорі, щоб після завершення відео автоматично вмикалося наступне.
- Приховує пропозиції «продовжити в застосунку TikTok» і блокує переспрямування до магазинів застосунків.
- Ви залишаєтеся в акаунті після перезапуску браузера.

Конфіденційність: розширення не збирає даних і нічого нікуди не надсилає, окрім самого TikTok.

Вихідний код: https://github.com/SubochArtem/tiktok-firefox-sidebar

Неофіційний проєкт. Не пов’язаний з TikTok і не схвалений TikTok.
```
