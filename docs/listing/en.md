# en

## Name

TikTok in Sidebar

## Summary

Watch TikTok in the Firefox sidebar while you browse. Optional auto-scroll to the next video. Unofficial, not affiliated with TikTok.

## Description

```text
Watch the TikTok feed in the Firefox sidebar while you keep working in the main window.

Features:
- TikTok in the sidebar: toggle it with the toolbar button or View → Sidebar → TikTok.
- Auto-scroll: tick the checkbox at the top to move to the next video when the current one ends.
- Hides "continue in the TikTok app" prompts and stops redirects to app stores.
- Keeps you logged in between browser restarts.

Privacy: the extension collects no data and sends nothing anywhere except to TikTok itself.

Source code: https://github.com/SubochArtem/tiktok-firefox-sidebar

Unofficial project. Not affiliated with or endorsed by TikTok.
```
